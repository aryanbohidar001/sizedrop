FAQ

Frequently asked questions

Is SizeDrop free?

Yes. This browser-based tool is designed for free static hosting and runs locally in your browser.

Are my images uploaded?

No. Image compression happens in your browser using JavaScript and the Canvas API, so your files stay on your device.

Can I compress JPG, PNG, and WebP files?

Yes. SizeDrop supports JPG, PNG, and WebP image compression with quality and size controls.

Can I compress PDFs online?

Yes. The PDF tool renders pages and rebuilds the file with smaller image quality, which is useful for scanned and image-heavy PDFs.

Will every file become smaller?

No. Already optimized files can stay the same size or occasionally become larger. The tool shows the actual result after compression.

Is there a file-size limit?

The interface is set to 50 MB per file. Very large files can still be limited by the phone or computer's available memory.
