# SizeDrop

## What is included
- Responsive homepage
- JPG/JPEG, PNG and WebP image compression
- Image resize
- Browser-side PDF rebuilding/compression
- Before/after size and savings
- FAQ
- Privacy Policy
- Terms
- SEO metadata + FAQ/WebApplication structured data
- AdSense-ready layout placeholder (no ads inserted)



## Important PDF note
The PDF feature rebuilds each page as a JPEG image. It is most effective for scanned/image-heavy PDFs. It may reduce text/vector quality and may not reduce already optimized PDFs.
