# SizeDrop — Netlify Free Version

## What is included
- Responsive homepage
- JPG/JPEG, PNG and WebP image compression
- Image resize
- Browser-side PDF rebuilding/compression
- Before/after size and savings
- FAQ
- Privacy Policy
- Terms
- SEO metadata + FAQ/WebApplication structured data
- AdSense-ready layout placeholder (no ads inserted)

## Deploy on Netlify
1. Create a free Netlify account.
2. Drag the project folder into Netlify's deploy area, or connect a GitHub repository.
3. Open the generated `.netlify.app` URL.
4. In `index.html`, replace `https://YOUR-SITE.netlify.app/` with your real URL.

## Important PDF note
The PDF feature rebuilds each page as a JPEG image. It is most effective for scanned/image-heavy PDFs. It may reduce text/vector quality and may not reduce already optimized PDFs.

## Before AdSense
Add your real contact details, privacy policy, terms, About page, and useful original content. Do not place ads over the main upload/compression controls. AdSense approval is determined by Google and is not guaranteed.
